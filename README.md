# Airbnb Data Mart

## Overview

This project was developed as part of the IU assignment “Build a Data Mart in SQL” (DLBDSPBDM01). It implements a MySQL database for an Airbnb-style accommodation booking platform, covering users, hosts, rentals, bookings, payments, reviews, and related services.


## How to Run

1. Clone or download this repository.

2. Open the SQL script in MySQL Workbench.

3. Connect to your MySQL Server.

4. Execute the script to create and populate the database.

5. Run the included queries to explore the data.
